CSV format

#class,Calculus I – Section 01
#rows,6
#seats_per_row,8
#aisles,4
class,name,student_id,email,row,seat,2026-10-13,2026-10-15
Calculus I – Section 01,Ana Garza,20480100,ana@example.edu,1,1,P,A
Calculus I – Section 01,Luis Pérez,20480137,luis@example.edu,1,2,E,P
Calculus I – Section 01,Mia Thompson,20480174,mia@example.edu,,,P,P

One row per student. Student fields come first — class, name (required; or first name + last name), student_id, email, row, seat — then one column per attendance date: P present (or blank), A absent, E excused.

  • Leaving row and seat blank (or leaving those columns out) places the student in the next open seat, front row first — so a plain roster export works.
  • Row 1 is the front row. Seat 1 is on the left as students face the front. Older files with a single seat column like A1 or 1-1 still import.
  • Date headers may be 2026-10-13 or 10/13/2026, as spreadsheets often rewrite them. Comma, semicolon, or tab separators all work.
  • Lines starting with # are optional settings (#aisles lists the seat each aisle follows, separated by spaces, like 3 6; leave it empty for none). Other columns are ignored, and you'll be told which.
  • class says which class each row belongs to. Rows go to the class with that name; a name that doesn't exist yet becomes a new class. A file without a class column goes into the class that's open. An All classes export lists every class's students in one file.
  • Classes meet on different days, so a date cell is blank for a class that didn't meet that day. A date is recorded for a class only if at least one of its students has a P, A, or E there; within a recorded date, a blank still means present.
  • The # layout lines describe one class's room, so they're included in single-class exports only. Rooms for every class are kept in the full .json backup.
  • The file holds roster, seating, and attendance. Email templates stay in this browser.

How Attendance works

Getting started

Type the class name and pick a class date at the top. Then switch to Edit seats to arrange the room and fill in the roster, or use Manage data to load a CSV. Demo data is included so you can try things out; replace it by editing, importing, or choosing Start an empty class.

Several classes in one file

Pick the class you're teaching from the Class menu at the top (or press C); everything you see belongs to that class only. ＋ New class adds one. Each class has its own roster, seats, and attendance, and uses a room that holds the layout (rows or tables, sizes, aisles). Sections that meet in the same room can share it; changing a shared room's layout is refused if it would leave another class's students without a seat, and Give this class its own copy splits it off. Rename, reassign, or delete classes and rooms under Manage data → Classes & rooms. Set the days each class meets in that list (or when creating it); then ‹ › and [ ] step between class days, the calendar highlights them, and the date bar warns on a day the class doesn't meet. The CSV can be the current class or All classes (with a class column); Back up all classes saves everything, rooms included, in one .json file. Download app with data saves a copy of this app with all classes (or just the open one), their rooms, your templates, and your settings built in; open that file anywhere to continue. The first time it opens somewhere new it loads its built-in data; if that browser already has data for that file's location, it asks once which to keep. When importing into a class that already exists, choose Update roster (the default: matches students by ID, then email, then name; updates their details, adds new students in open seats, applies any P/A/E marks in the file, and keeps everyone's seat and history; blank cells change nothing) or Replace everything (the file becomes the class's whole roster, seating, and attendance).

Choosing the class date

The date bar under the tabs shows which day you're working on. It appears on every view that uses a date. Its badge says Today in green. Any other day turns the bar amber (past) or blue (future) with a ⚠ warning, and while you're marking seats or drafting emails an amber frame surrounds the whole window, so you can't miss that you're working on another day. The chips jump to Today or a recent class date; red numbers show how many were absent that day. Use ‹ and › to step one day, click the date to open a large calendar (arrow keys move by day and week, PgUp/PgDn by month, Enter picks, Esc or clicking elsewhere closes it), press Go to today, or tap one of the recent class dates. Keyboard: [ previous day, ] next day, T today, U unlock.

To protect your records, seats are locked on any day other than today. Press Edit this date to unlock it for corrections; it stays unlocked until you reload the page. The Attendance history grid is always editable.

Taking attendance

  • Every assigned seat starts as Present for the selected date — you only mark exceptions.
  • Click a seat to cycle Present → Absent → Excused. With a seat focused you can also press P, A, or E.
  • A date is saved to the history as soon as you mark an exception, or press Record date if everyone is present.
  • The summary shows assigned, present, absent, and excused counts for the selected date.

Editing seats

  • Select a seat to enter a name, student ID, and email, then press Save seat. Students are removed only in Manage data: the roster's Remove button asks whether to drop them (off the chart, attendance, and emails, with their past attendance kept under Dropped students, where they can be restored) or delete them completely. Seats can't be cleared from the Classroom view, so a stray click there never removes anyone.
  • Drag a student onto another seat to move them (or swap if the seat is taken). Without a mouse, enter a row and seat number under Move / swap with.
  • Under Room layout, choose the Room shape. Tables / pods draws each table with its seats around it (numbered clockwise from top-left); set the number of tables, seats per table, and how many tables sit side by side. Seats are then named “Table 3, Seat 2” everywhere. Switching shape keeps everyone where they fit and offers to move anyone else into open seats; attendance is never lost.
  • For a Rows room, set rows and seats per row. To add an aisle, click the faint + between two seat columns at the top of the chart; click × to remove it. You can have as many aisles as the room needs. Shrinking is refused if it would remove assigned students; empty seats stay available for later.

Instructor view

Turns the chart 180° so it matches what you see from the front of the room. Seat labels and attendance don't change.

Manage data

CSV is how you back up, restore, and move your data. With Manage data open, drag a CSV file anywhere onto the page, or choose one with the file picker; you'll see a summary to confirm before anything is replaced. Each row is one student: name, student ID, email, row, and seat, followed by one column per attendance date. Importing replaces the current roster, seating, and attendance. Students with no seat are placed in open seats, so a plain roster from another system imports directly. Download a full CSV from that page at any time as a backup.

Attendance history

One row per student and one column for every recorded date, with absence and excused totals. To go to a date, use Jump to date, the date bar, its calendar (G), or [ / ] to hop between recorded dates. The grid scrolls to that column, flashes it, and puts the cursor there. Type in Find student (or press /) to show only matching students. It is editable: click any cell to cycle Present → Absent → Excused, or focus it and press P, A, or E. Use Add date to record a day where everyone was present, and × in a column header to delete that date. Classroom and history edit the same records, so a change in one shows up in the other immediately.

Emails

The Subject and Message on the left are the email being drafted, and the drafts on the right update as you type. Picking a template loads it as a starting point. Your edits are used right away without saving; an “Edited” note appears with Revert to go back. Save template keeps your edits in that template, and Duplicate saves them as a new one. Your draft is kept if you reload.

Keep a library of response templates on the left. On the right, choose recipients. Students absent on the selected date are pre-selected. The filter buttons (All, Absent, Excused, Absent 2+ times) choose which students are listed, and only those students are shown. Picking Absent, Excused, or Absent 2+ times also selects everyone it lists, which you can then trim. Picking All shows the whole class without selecting anyone extra. Use the − and + beside “Absent 2+ times” to change the number (for example, 3+ or 4+); the list and selection update right away and the number is remembered. Search narrows the list further; Shift-click selects a range. If a selected student is hidden by your search, the count says so.

  • One email (BCC) writes a single message with every selected address on the BCC line, so students can't see each other's addresses. You can put your own address in To. Personal placeholders like {first} become “everyone”.
  • Separate emails keeps the personal version: one draft per student with their name filled in.

Open in mail app starts an unsent message, Download .eml saves a draft file that Outlook and many other mail apps open as unsent, and Copy puts the text on your clipboard. Nothing is ever sent automatically.
