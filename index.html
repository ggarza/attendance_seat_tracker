CSV format

#class,Calculus I – Section 01
#rows,6
#seats_per_row,8
#aisles,4
class,name,email,row,seat,2026-10-13,2026-10-15
Calculus I – Section 01,Ana Garza,ana@example.edu,1,1,P,A
Calculus I – Section 01,Luis Pérez,luis@example.edu,1,2,E,P
Calculus I – Section 01,Mia Thompson,mia@example.edu,,,P,P

One row per student. Student fields come first — class, name (required; or first name + last name), email, row, seat — then one column per attendance date: P present (or blank), A absent, E excused.

  • Leaving row and seat blank (or leaving those columns out) places the student in the next open seat, front row first — so a plain roster export works.
  • Row 1 is the front row. Seat 1 is on the left as students face the front. Older files with a single seat column like A1 or 1-1 still import.
  • Date headers may be 2026-10-13 or 10/13/2026, as spreadsheets often rewrite them. Comma, semicolon, or tab separators all work.
  • Lines starting with # are optional settings (#aisles lists the seat each aisle follows, separated by spaces, like 3 6; leave it empty for none). Other columns are ignored, and you'll be told which.
  • class says which class each row belongs to. Rows go to the class with that name; a name that doesn't exist yet becomes a new class. A file without a class column goes into the class that's open. An All classes export lists every class's students in one file.
  • Classes meet on different days, so a date cell is blank for a class that didn't meet that day. A date is recorded for a class only if at least one of its students has a P, A, or E there; within a recorded date, a blank still means present.
  • The # layout lines describe one class's room, so they're included in single-class exports only. Rooms for every class are kept in the full .json backup.
  • The file holds roster, seating, and attendance. Email templates stay in this browser.

How Attendance works

🔒 Nothing is saved online: attendance records stay in this browser and are never uploaded, keeping student records private under FERPA.

Getting started

Type the class name and pick a class date at the top. Then switch to Edit seats to arrange the room and fill in the roster, or use Manage data to load a CSV. Demo data is included so you can try things out; replace it by editing, importing, or choosing Start an empty class.

Several classes in one file

Pick the class you're teaching from the Class menu at the top (or press C); everything you see belongs to that class only. ＋ New class adds one. Each class has its own roster, seats, and attendance, and uses a room that holds the layout (rows or tables, sizes, aisles). Sections that meet in the same room can share it; changing a shared room's layout is refused if it would leave another class's students without a seat, and Give this class its own copy splits it off. Rename, reassign, or delete classes and rooms under Manage data → Classes & rooms. Set the days each class meets in that list (or when creating it); then ‹ › and [ ] step between class days, the calendar highlights them, and the date bar warns on a day the class doesn't meet. The CSV can be the current class or All classes (with a class column); Download backup (top of Manage data, or Ctrl/⌘+S) saves everything, rooms included, in one .json file. Saved data belongs to this app's web address in this browser; if the address changes (a renamed or moved file), Manage data → Recover data lists data saved under the old address, plus an automatic copy from each of the last 7 days, and can bring any of it back. Download app with data saves a copy of this app with all classes (or just the open one), their rooms, your templates, and your settings built in; open that file anywhere to continue. The first time it opens somewhere new it loads its built-in data; if that browser already has data for that file's location, it asks once which to keep. When importing into a class that already exists, choose Update roster (the default: matches students by email, then name; updates their details, adds new students in open seats, applies any P/A/E marks in the file, and keeps everyone's seat and history; blank cells change nothing) or Replace everything (the file becomes the class's whole roster, seating, and attendance).

Choosing the class date

The date bar under the tabs shows which day you're working on. It appears on every view that uses a date. Its badge says Today in green. Any other day turns the bar amber (past) or blue (future) with a ⚠ warning, and while you're marking seats or drafting emails an amber frame surrounds the whole window, so you can't miss that you're working on another day. The chips jump to Today or a recent class date; red numbers show how many were absent that day. Use ‹ and › to step one day, click the date to open a large calendar (arrow keys move by day and week, PgUp/PgDn by month, Enter picks, Esc or clicking elsewhere closes it), press Go to today, or tap one of the recent class dates. Keyboard: [ previous day, ] next day, T today, U unlock.

To protect your records, seats are locked on any day other than today. Press Edit this date to unlock it for corrections; it stays unlocked until you reload the page. The Review history grid is always editable.

List view and sign-in sheets

In Take attendance, switch Seating chart | List (or press L). The list is sorted by last name, the same order as the printed sign-in sheet. One date shows P / A / E buttons for the selected date; Sheet shows every date on one printed sheet side by side, so you can enter a filled sheet in one pass (sheet columns stay editable on past dates). Mark with P A E or the side-by-side Q W E. The × next to “✓ recorded” deletes that date's records, like × in History (Ctrl/⌘+Z undoes). Start everyone as Present | Absent decides what an unrecorded date means: with Absent, mark the students who initialed; your first mark records the date with everyone else absent. Unrecorded dates are shown dimmed.

Sign-in sheet PDF… makes a printable sheet (landscape or portrait): last name, first name, then date columns, either printed with the class's next meeting dates or left blank for students to write in. Each sheet is numbered; pick it in Sheet mode to transcribe it (for a blank sheet, set each column's date there), and PDF prints it again. Choose the row height, or Fit everyone on one page. Sheet mode doesn't need a printed sheet: Recent class dates is always available, and Create without PDF makes a sheet just for entering attendance.

Taking attendance

  • Every assigned seat starts as Present for the selected date — you only mark exceptions.
  • Click a seat to cycle Present → Absent → Excused. With a seat focused you can also press P, A, or E.
  • A date is saved to the history as soon as you mark an exception, or press Record date if everyone is present.
  • The summary shows assigned, present, absent, and excused counts for the selected date.

Editing seats

  • Select a seat to enter a first name, last name, and email, then press Save seat. Students are removed only in Manage data: the roster's Remove button asks whether to drop them (off the chart, attendance, and emails, with their past attendance kept under Dropped students, where they can be restored) or delete them completely. Seats can't be cleared from the Take attendance view, so a stray click there never removes anyone.
  • Drag a student onto another seat to move them (or swap if the seat is taken). Without a mouse, enter a row and seat number under Move / swap with.
  • Under Room layout, choose the Room shape. Tables / pods draws each table with its seats around it (numbered clockwise from top-left); set the number of tables, seats per table, and how many tables sit side by side. Seats are then named “Table 3, Seat 2” everywhere. Switching shape keeps everyone where they fit and offers to move anyone else into open seats; attendance is never lost.
  • For a Rows room, set rows and seats per row. To add an aisle, click the faint + between two seat columns at the top of the chart; click × to remove it. You can have as many aisles as the room needs. Shrinking is refused if it would remove assigned students; empty seats stay available for later.

Instructor view

Turns the chart 180° so it matches what you see from the front of the room. Seat labels and attendance don't change.

Storage

Browsers give each site about 5 MB for this kind of data; a busy semester with several classes uses well under 1 MB. The backup card shows how much is used. If space runs out, the oldest automatic copies are removed first so your changes still save. The app also asks the browser to keep its data rather than clear it when the computer is low on space (in Safari, adding the app to the Dock or Home Screen does the same). At the end of a semester: download a backup, then delete the classes you've finished. The app follows UTRGV's academic calendar: the day after grades are due (for Fall 2026, December 15), a reminder appears if a class was used that term and no class has been created since it ended. Remind me next week snoozes it; Done dismisses it for that term; creating a class for the new term ends it.

Backups, restoring, and recently deleted

Download backup saves everything in one .json file. Restore a backup… (or dropping a .json on Manage data) offers Merge with what's here (the default) or Replace everything. Merge never removes anything: it adds the classes, students, dates, marks, notes, emails sent, sign-in sheets, and templates that the backup has and this device doesn't, so you can go back and forth between a computer and an iPad. If both have a different mark for the same student and date, you choose whose marks win. Students dropped in the backup are dropped here too (you can uncheck that), and students dropped here but active in the backup can be restored. Either way, what's here is saved as an automatic copy first. Deleted students, dates, classes, rooms, and templates, and cleared classes, go to Recently deleted for 30 days, where Restore puts them back (with their attendance, notes, and seat when it's still free) and Delete forever removes them for good.

Importing a roster

Each class in Manage data → Classes & rooms has Import…: choose a CSV (or paste one) and everything in it goes into that class, whatever class column the file has. Update roster (the default) matches students and keeps seats and history; Replace everything makes the file the class's whole roster. For a file with several classes, use Import a CSV just below the class list; rows go to the class named in each row.

＋ New class asks for the class name, meeting days, and room, and, optionally, a roster file (a Brightspace classlist export, a CSV with last_name, first_name, and email, or pasted names) and a video guide (.md). Each has a short formatting guide and a check mark showing what was found before you create the class. A class with no students shows an Import a roster button in every view.

Video guides and the day's topic

Each class can have a video guide: a Markdown file listing your course topics with a focus line and video links. Load it with Video guide… on the class in Manage data → Classes & rooms (you can use the same file for other sections). Each ### heading is a topic, ## headings group them, a **Focus:** line is the focus, and bulleted links are the videos. Then in Send emails, pick what was covered from the Topic menu under the date (press ＋ to add another topic, × to remove one); it's remembered for that class and date. With several topics, {topic} lists them all, {focus} gives one line per topic, and {videos} groups the links by topic. {topic}, {focus}, and {videos} fill in from it, and with no topic picked, any paragraph using them is left out. Six starter templates are built around them, starting with “Videos for the day you missed”, and every other starter has an optional “If it helps, these videos cover…” paragraph that only appears when a topic is picked.

Checking for drops

In Manage data → Classes & rooms, press Check for drops… on a class, choose a new class list (a Brightspace classlist export works; only names are needed) or paste names, one per line, and press Compare. It's compared with that class: students matched by email or name (accents, case, name order, and extra surnames don't matter) are fine; names that are close but not identical are listed under Check these for you to confirm; and anyone missing from the new list is listed with their absences and last day present. Drop checked students drops them as of the date you choose, keeping their attendance. Students in the new list who aren't in the class can be added to open seats, and anyone you'd marked dropped who is back on the list can be restored. Instructors and TAs in a Brightspace file are skipped.

Manage data

CSV is how you back up, restore, and move your data. With Manage data open, drag a CSV file anywhere onto the page, or choose one with the file picker; you'll see a summary to confirm before anything is replaced. Each row is one student: name, email, row, and seat, followed by one column per attendance date. Importing replaces the current roster, seating, and attendance. Students with no seat are placed in open seats, so a plain roster from another system imports directly. Download a full CSV from that page at any time as a backup.

Notes, the email log, and student summaries

Notes: any student on any date can have a short note (“doctor's note received”, “left early”). Press N on a seat, a list row, a sheet cell, or a history cell, or use the Note column in the list view. A small yellow dot marks cells with a note, notes for the day are listed beside the classroom, and they appear next to students in Send emails. Ctrl/⌘+Z undoes a note change. Email log: when you open a draft in your mail app, download a .eml, or copy addresses or a personal email, Attendance records who it was for, the date it was about, and the subject. Students already emailed about the selected date show “✉ sent”, a warning appears before you email them again, and history marks those cells with ✉. The app can't see your mail app, so remove any log entry you didn't actually send. Student summary: press I (or Summary in the history bar) for one student's totals, attendance rate, absences and excused days with notes, and the emails sent; Print gives a clean one-page copy, and Email this student opens Send emails with just them selected.

Review history

One row per student and one column for every recorded date, with absence and excused totals. To go to a date, use Jump to date, the date bar, its calendar (G), or [ / ] to hop between recorded dates. The grid scrolls to that column, flashes it, and puts the cursor there. Type in Find student (or press /) to show only matching students. Click the Last name, First name, Row (seat order), Absent, or Excused header to sort; click it again to reverse. Absences and excused sort most-first, and the sort is remembered. While you mark cells, rows stay where they are so the cursor doesn't jump; press ↻ Re-sort (or Esc) to refresh the order. It is editable: click any cell to cycle Present → Absent → Excused, or focus it and press P, A, or E. Use Add date to record a day where everyone was present, and × in a column header to delete that date. Take attendance and Review history edit the same records, so a change in one shows up in the other immediately.

Send emails

The Subject and Message on the left are the email being drafted, and the drafts on the right update as you type. Picking a template loads it as a starting point. Your edits are used right away without saving; an “Edited” note appears with Revert to go back. Save template keeps your edits in that template, and Duplicate saves them as a new one. Your draft is kept if you reload. A starter template you've changed and saved is marked (edited) in the template menu, with Restore original wording under its title; your edited version goes to Recently deleted, so it can be brought back as its own template. Type your name in Your name for {instructor} (above Save template) and it fills {instructor}, which the starter templates use under their closing; leave it blank and that line is simply left out. Office hours and Office next to it fill {officehours} and {office} the same way; the four office-hours templates list them on their own lines, so a blank one just disappears.

Keep a library of response templates on the left. On the right, choose recipients. Students absent on the selected date are pre-selected. The filter buttons (All, Absent, Excused, Absent 2+ times) choose which students are listed, and only those students are shown. Picking Absent, Excused, or Absent 2+ times also selects everyone it lists, which you can then trim. Picking All shows the whole class without selecting anyone extra. Use the − and + beside “Absent 2+ times” to change the number (for example, 3+ or 4+); the list and selection update right away and the number is remembered. Search narrows the list further; Shift-click selects a range. If a selected student is hidden by your search, the count says so.

  • One email (BCC) writes a single message with every selected address on the BCC line, so students can't see each other's addresses. You can put your own address in To. Personal placeholders like {first} become “everyone”.
  • Separate emails keeps the personal version: one draft per student with their name filled in.

Open in mail app starts an unsent message, Download .eml saves a draft file that Outlook and many other mail apps open as unsent, and Copy puts the text on your clipboard. Nothing is ever sent automatically.
